.. _dataset-examples:

Dataset examples
----------------

One dataset per family (audio, radar micro-Doppler, satellite image time
series, hyperspectral, SAR): load it, look at it, check its covariances and its
leakage-free split. These scripts need the dataset under ``$SPDNET_DATA_ROOT``
(see :doc:`/guide/fetch`), so they are not executed when the documentation is
built; the figures are those of the dataset pages.
